## 2. Implemented changes

### Canonical requirement ledger

- `document_coverage_summary` / `build_requirement_ledger` in `assessment_contracts.py`
- Required coverage = satisfied required groups ÷ total required groups × 100
- Partial gets no full-satisfaction credit; uncertain stays in denominator; empty → unavailable; incomplete extraction withholds %
- Preferred coverage calculated separately
- `evaluate_requirements` returns `ledger`, `required_coverage`, `preferred_coverage`
- `resume_scorer._deterministic_scores` uses ledger as sole coverage source; keyword/skills bars agree; term presence is advisory only
- `compute_assessment_stages` persists ledger fields
- Layout warnings never change coverage math

### UI

- Heading: **CareerOS ATS assessment**
- Required coverage with exact counts; preferred separate; expandable ledger rows
- File checks and human review separate
- Disclaimer note; empty employer/vendor card removed
- Overlapping unexplained keyword/skills bars removed from primary display

### Pagination

- `RENDER_VERSION = 2026-09-05.1`
- `section_header(..., keep_with_mm=)` breaks **before** heading when heading+first block won’t fit
- Dense-gap retry for avoidable sparse spill; sparse final page → advisory warning
- DOCX: `keep_with_next` on section headers and first education school line
- Content never deleted to force one page
