# Local-dev install target (see README.md: `pip install -r requirements.txt`).
#
# Local dev runs all 4 services as ONE Flask app via local.py, which mounts
# shared/python on sys.path — so locally you need exactly the deps prod bundles
# into the shared Lambda LAYER. Install that set to avoid drift; it is the single
# source of truth for runtime dependencies.
#
# All runtime deps live in shared/python/requirements.txt (the layer). Services
# carry NO per-service requirements — package.sh bundles only code, deps come
# from the layer. Test-only deps (pytest, mongomock, openpyxl) → requirements-dev.txt.
-r shared/python/requirements.txt
